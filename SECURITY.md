# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability in AalaAI, please do not publish sensitive details publicly before the issue can be reviewed.

Instead, contact the project maintainer privately through GitHub.

When reporting a security issue, please include:

* A clear description of the issue
* Steps to reproduce it
* Possible impact
* Screenshots or logs if relevant
* Any suggested fix, if available

## Supported Versions

AalaAI is currently in early development.

Security fixes will mainly be applied to the latest available version.

## Responsible Disclosure

Please allow reasonable time for the issue to be investigated and fixed before publicly sharing vulnerability details.

Thank you for helping keep AalaAI secure.
